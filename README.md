# 중앙대학교 인문대학 제15대 학생회 ‘역’ 공식 페이지

링크트리를 대신하는 학생회 공식 링크 페이지입니다. **공지 업로드**가 중심 기능이고,
신청 폼·SNS 등 흩어져 있던 링크를 한 화면에 모읍니다.

- 서버·데이터베이스 없이 동작하는 **정적 사이트**입니다. (GitHub Pages 무료 호스팅)
- 빌드 도구가 필요 없습니다. 파일을 수정해 커밋하면 그대로 반영됩니다.
- 핵심 컬러: **`#F8E9D4` 샌드베이지**

---

## 1. 폴더 구조

```
index.html        홈 (로고 · 최근 공지 · 링크 모음 · 학생회 소개)
notices.html      전체 공지 목록 (분류 필터 + 검색)
notice.html       공지 상세  (notice.html?id=공지아이디)
admin.html        공지 작성 도구 ★ 학생회에서 실제로 쓰는 화면
css/style.css     디자인 전체
js/config.js      ★ 링크 · 학생회 소개 · 연락처 설정
js/core.js        공통 기능 (데이터 로딩, 본문 렌더링 등)
js/pages.js       홈 · 목록 · 상세 화면 동작
js/admin.js       공지 작성 도구 동작
data/notices.json ★ 공지 데이터 (이 파일이 곧 공지 게시판입니다)
assets/           로고 · 아이콘 · 공지 이미지
```

★ 표시된 세 곳만 만지면 대부분의 운영이 가능합니다.

## 2. 시작하기 전에 (최초 1회)

### 2-1. 로고 넣기

학생회 로고 원본을 `assets/logo.png` 로 저장하세요.
(투명 배경 정사각형 PNG, 512×512px 이상 권장)

파일이 없으면 ‘역’ 글자 대체 마크가 자동으로 표시되므로 화면이 깨지지는 않지만,
실제 로고를 넣어야 완성된 모습이 됩니다.

### 2-2. 링크 채우기

`js/config.js` 를 열고 `url: ''` 로 비어 있는 항목에 실제 주소를 넣으세요.
비워두면 화면에 **‘준비 중’** 으로 표시됩니다.

현재 채워야 하는 곳:

- 카카오톡 채널 주소
- 학생회 건의함(구글폼) 주소
- 사업 신청 폼 주소
- 학생회비 납부 안내 주소
- 연락 이메일 (`contact.email`)

### 2-3. 예시 공지 지우기

`data/notices.json` 에 들어 있는 `[예시]` 공지 3건은 사용법 안내용입니다.
운영을 시작하기 전에 `admin.html` 의 **‘예시 공지 지우기’** 버튼으로 정리하세요.

### 2-4. GitHub Pages 켜기

저장소 → **Settings** → **Pages** →
**Source: Deploy from a branch**, **Branch: `main` / `(root)`** → Save.

1~2분 뒤 `https://cau-inmun.github.io/page/` 에서 열립니다.

### 2-5. 카카오톡 공유 미리보기 (권장)

주소가 확정되면 `index.html` · `notices.html` · `notice.html` 의
`og:image` 를 **전체 주소**로 바꿔주세요. 카카오톡·인스타그램은 상대 경로 이미지를 읽지 못합니다.

```html
<!-- 이렇게 -->
<meta property="og:image" content="https://cau-inmun.github.io/page/assets/logo.png">
```

## 3. 공지 올리는 방법 (평소 운영)

1. 브라우저에서 **`admin.html`** 을 엽니다.
   (배포된 사이트에서 `.../admin.html` 로 접속하거나, 파일을 직접 열어도 됩니다)
2. 제목 · 분류 · 날짜 · 내용을 채웁니다. 오른쪽 **미리보기**로 실제 화면을 확인할 수 있습니다.
3. **‘목록에 추가’** 를 누릅니다.
4. 맨 아래 **‘JSON 내려받기’** 를 눌러 `notices.json` 을 받습니다.
5. GitHub 에서 `data/notices.json` 을 열고 → 연필(✏️) 아이콘 → 내용을 방금 받은 파일로 **전체 교체** → **Commit changes**.
6. 1~2분 뒤 사이트에 반영됩니다.

> 작성 중인 내용은 브라우저에 임시 저장되므로, 창을 닫았다 다시 열어도 이어서 쓸 수 있습니다.
> 다만 **JSON 을 내려받아 커밋해야 실제 사이트에 올라갑니다.**

### 본문에서 쓸 수 있는 문법

| 입력 | 결과 |
| --- | --- |
| `## 소제목` | 소제목 |
| `- 항목` | 목록 |
| `1. 항목` | 번호 목록 |
| `**굵게**` | **굵게** |
| `*기울임*` | *기울임* |
| `` `강조` `` | 코드 형태 강조 |
| `[보이는 글자](https://주소)` | 링크 |
| `> 인용문` | 인용 상자 |
| `---` | 구분선 |

### 공지에 포스터 이미지 넣기

1. 이미지를 `assets/` 폴더에 올립니다. (예: `assets/poster-0908.jpg`)
2. 작성 도구의 **이미지 주소** 칸에 `assets/poster-0908.jpg` 를 적습니다.

## 5. 자주 묻는 것

**Q. 공지가 안 보여요.**
`data/notices.json` 문법이 깨졌을 가능성이 높습니다. 쉼표(`,`)나 큰따옴표가 빠지지 않았는지 확인하세요.
작성 도구에서 내려받은 파일을 그대로 쓰면 이 문제가 생기지 않습니다.

**Q. 공지 순서를 바꾸고 싶어요.**
날짜가 최신인 순으로 자동 정렬됩니다. 맨 위에 두고 싶은 공지는 **‘목록 맨 위에 고정하기’** 를 켜세요.

**Q. 분류를 추가하고 싶어요.**
`js/config.js` 의 `categories` 에 이름을 추가하고, 색을 따로 주려면
`css/style.css` 의 `.tag[data-cat="..."]` 규칙을 복사해 추가하세요.

**Q. admin.html 을 아무나 볼 수 있는 것 아닌가요?**
볼 수는 있지만 **사이트를 바꿀 수는 없습니다.** 이 도구는 JSON 파일을 만들어줄 뿐이고,
실제 반영은 저장소에 커밋 권한이 있는 사람만 할 수 있습니다. (검색엔진에는 노출되지 않도록 설정되어 있습니다)
