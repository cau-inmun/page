# 모바일 디자인 변경 기록

2026-09-09

반복되던 카드와 큰 로고 중심 구성을 바꾸고, 공지와 자주 찾는 메뉴가 먼저 보이도록 정리했습니다.

- 핵심 색 `#F8E9D4`에 짙은 남색 `#182C46`을 조합했습니다.
- 사용자가 제공한 인문대학 푸앙과 문장을 원본 그대로 사용했습니다. 기존 학생회 로고도 유지합니다.
- 홈의 소개, 바로가기, 공지, 사업, 링크, 집행국에 서로 다른 정보 위계와 간격을 적용했습니다.
- 680px 이하에서는 홈·공지·열람실·신청·링크 메뉴를 하단에 고정합니다. 하단 안전 영역과 본문 여백을 확보합니다.
- 공지 목록·상세, 신청·건의, 열람실에도 공개 페이지의 서체·색상·버튼 규격을 적용했습니다.
- 바로가기는 서버 설정을 기다리는 동안 캐시 또는 기본 설정으로 먼저 표시합니다. 설정이 도착하면 관리자 설정으로 갱신합니다.

## 수정 위치

공개 페이지 스타일은 `css/redesign.css`에서 관리합니다. `css/style.css` 뒤에 읽으며 `public-site` 클래스가 있는 다섯 공개 페이지에 적용됩니다. 본문은 프리텐다드, 주요 제목은 기존에 선언되어 있던 페이퍼로지를 사용합니다.

문구·링크·학생회 정보는 기존 `js/config.js` 및 관리자 설정을 계속 사용합니다. Firebase 설정, 공지 데이터, 제출·예약·관리 기능과 보안 규칙은 변경하지 않았습니다. 관리자와 진단 HTML의 변경은 캐시 버전 갱신입니다.

## 백업

- 원본 커밋: `a28c58664ad7e4ff068a45961b1e0336a898e08c`
- [원본 백업 브랜치](https://github.com/cau-inmun/page/tree/backup/before-mobile-redesign-20260909)
- 변경 브랜치: `design/mobile-editorial-20260909`

백업 브랜치는 변경 전 코드와 이미지 전체를 보관합니다. 디자인 병합 이후 되돌릴 때는 해당 병합 커밋을 revert하여 후속 변경 기록을 보존할 수 있습니다. Firebase의 운영 데이터는 Git 백업 대상이 아니며 이번 작업에서 수정하지 않았습니다.

## 확인한 내용

- 모든 JavaScript 파일의 구문 검사
- HTML 7개의 로컬 파일 경로, 중복 ID, 기존 데이터 속성 보존
- 모든 진입 HTML과 `APP_VERSION`의 캐시 버전 일치
- 원본 대비 데이터·예약·신청·관리·보안 규칙 파일의 일치
- 주요 본문과 버튼의 색상 대비 계산
- `git diff --check`

실제 브라우저 및 기기에서의 시각 검수와 운영 서버에 접수·예약하는 테스트는 수행하지 않았습니다. 공개 페이지 반영은 변경 브랜치를 `main`에 병합한 뒤 기존 GitHub Pages 배포 절차를 따릅니다.
