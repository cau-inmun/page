# 홈페이지 편집 안내

주소: https://cau-inmun.github.io/page/ · 저장소: https://github.com/cau-inmun/page

## 먼저 구분하기

- **관리자 화면에서 바꿀 수 있는 내용**은 `admin.html`에 로그인해 저장하는 것이 가장 간단합니다. 저장값은 Firestore에 들어가며, 공개 화면에는 이 값이 `js/config.js`의 기본값보다 우선 적용됩니다.
- **코드에서 바꾸는 내용**은 아래 표의 파일을 수정한 뒤 GitHub 저장소에 반영해야 합니다. `js/config.js`만 바꿨는데 화면이 그대로라면 관리자 화면에 이미 저장된 값이 덮어쓰고 있을 수 있습니다.
- 화면을 구성하는 HTML, 동작을 담당하는 JavaScript, 색과 간격을 담당하는 CSS는 서로 역할이 다릅니다.

## 무엇을 어디서 바꾸나요?

| 바꾸고 싶은 것 | 가장 쉬운 방법 | 코드에서 수정할 곳 |
| --- | --- | --- |
| 학생회 이름, 메인 문구, 대학 이름 | 관리자 → **사이트 정보** → 이름과 제목 | `js/config.js`의 `brand`, `college`, `councilTerm`, `councilName`, `tagline` |
| 하단 주소, 인스타그램, 카카오톡, 이메일 | 관리자 → **사이트 정보** → 연락처 (푸터) | `js/config.js`의 `contact` 기본값. 줄바꿈은 `\n` |
| 메인에 보일 공지·신청 항목과 순서 | 관리자 → **사이트 정보** → 메인화면 노출 | 선택값은 Firestore의 사이트 정보에 저장. 출력 방식은 `js/home.js`의 `renderPreviews()` |
| 공지의 제목·본문·게시 기간 | 관리자 → **공지** | 기본 예시만 `data/notices.json`; 실제 운영 공지는 Firestore에 저장 |
| 신청 폼의 문항·접수 기간 | 관리자 → **폼 설정** | 초기 양식은 `js/config.js`의 `defaultForms` |
| 인증 사진 안내 문구 | 코드 수정 | `js/config.js`의 `verificationText`, `verificationHelp`, `photoConsentText`, `consentText`. 이미 관리자에서 저장한 사이트 정보가 있으면 관리자 화면의 기존 동의 문구도 수정 |
| 건의함의 기존 ‘익명’ 소개 문구 | 관리자 → **폼 설정** → 학생회 건의함 | 인증 사진을 받으므로 이름을 비워도 완전한 익명 접수가 아닙니다. 저장된 옛 문구는 화면에서 바로잡아 표시합니다. |
| 분실물 신고 문항과 완료 문구 | 관리자 → **폼 설정** → 분실물 신고 | 처음 제공되는 양식은 `js/config.js`의 `defaultForms` 중 `id: 'lost-found'` |
| 링크 페이지의 버튼·주소 | 관리자 → **링크** | 초기 목록은 `js/config.js`의 `linkGroups` |
| 인문대학 학부·전공 목록과 이동 주소 | 코드 수정 | `js/config.js`의 `majors`; `children`이 있는 학부는 눌러 펼침 |
| 학생회 소개 글·집행부 | 관리자 → **사이트 정보** → 학생회 소개 | `js/config.js`의 `about` |
| 열람실 이름·호실·좌석 배치·이용 안내 | 코드 수정 | `js/config.js`의 `readingRoom`: `name`, `place`, `grid`, `seatNotes`, `notes` |
| 열람실 예약 동작 | 코드 수정 | `js/seats.js` 및 `js/store.js`; 보안 규칙과 맞물리는 변경은 `firestore.rules`도 함께 검토 |
| 열람실 예약 시작·초기화 시각 | 코드 수정 | `js/config.js`의 `readingRoom.openHour`, `closeHour`. 시간을 바꾸면 `firestore.rules`의 `inOpenHours()`도 같은 시각으로 수정 |
| 18시 이후 예약 허용·닫기 | 관리자 → **열람실** → **18시 이후 예약 허용** | 설정은 Firestore `config/seatControl`에 저장되고, 한국 시각 자정에 자동 만료 |
| 인증 사진 확인·삭제 | 관리자 → **접수 내역** 또는 **열람실** | 사진은 관리자 화면에서 열람. 응답 삭제 시 첨부 사진도 삭제; 지난 열람실 구간은 **선택한 구간의 인증 사진 삭제** |
| 상단·하단 메뉴의 이름과 이동 주소 | 코드 수정 | 각 페이지의 `.html` 파일에 있는 `<nav>`; 메인 큰 메뉴는 `index.html`의 `.home-menu` |
| 메인 화면의 배치·문구·이미지 | 코드 수정 | `index.html`, `js/home.js`, `assets/` |
| 열람실 화면의 배치 | 코드 수정 | `seats.html`; 좌석표는 `js/config.js`의 `readingRoom.grid`와 `js/seats.js`가 생성 |
| 푸터의 표시 순서·링크 이름 | 코드 수정 | 공통 출력은 `js/core.js`의 `renderFooter()`; 열람실 푸터의 HTML 틀은 `seats.html` |
| 색·글자 크기·여백·모바일 화면 | 코드 수정 | 주로 `css/redesign.css`, 기본 스타일은 `css/style.css`, 글꼴 주소는 각 HTML의 프리텐다드 `<link>` |

### 푸터를 바꾸는 예

1. **주소만 변경:** 관리자 → 사이트 정보 → 연락처 (푸터) → 주소 → **사이트 정보 저장**. 홈과 열람실에서 같은 주소를 사용합니다.
2. **인스타그램 링크 변경:** 같은 화면의 인스타그램 주소를 수정합니다. 빈칸이면 링크가 보이지 않습니다.
3. **푸터의 디자인 변경:** `css/redesign.css`에서 `.footer`, `.footer__inner`, `.footer__links`를 수정합니다.
4. **열람실 푸터의 문장이나 문장 이미지 변경:** `seats.html`의 `<footer class="footer">` 안을 수정합니다. 홈 푸터의 틀은 `index.html`에 있습니다.

`js/core.js`의 `renderFooter()`는 푸터 이름·주소·문의 링크를 공통 설정에서 읽습니다. 빈 이메일은 표시하지 않고, 외부 링크만 새 창으로 엽니다.

## 코드 수정 후 반영 순서

1. 수정한 파일을 저장하고 로컬에서 해당 페이지를 확인합니다.
2. `js/config.js`의 `APP_VERSION`을 새 값으로 바꾸고, **모든 HTML**의 `?v=` 값도 같은 값으로 바꿉니다. `js/admin.js`의 엑셀 모듈 주소에도 버전이 있습니다. 이 숫자는 브라우저가 옛 파일을 계속 보여주지 않도록 합니다.
3. GitHub 저장소에 변경사항을 커밋하고 푸시합니다. GitHub Pages 배포 후 홈과 열람실을 각각 새로고침해 확인합니다.

기존 `README.md`의 Firebase 설정·보안 규칙·장애 대응 설명도 함께 참고하세요. 실제 운영 데이터(공지, 폼 응답, 관리자 저장값)는 GitHub 파일과 별도로 Firestore에 보관됩니다.

## Firebase 규칙 반영

사진 제출과 새 예약 시간은 `firestore.rules`가 Firebase에 게시되어야 동작합니다. 인문대 계정으로 [Firebase 콘솔](https://console.firebase.google.com/project/cau-inmun/firestore/rules)에 로그인해 **Firestore Database → 규칙**을 열고, 저장소의 `firestore.rules` **전체 내용을 복사해 기존 규칙 전체와 교체한 뒤 게시**하세요. 일부만 덧붙이면 기존 규칙과 충돌할 수 있습니다. 규칙은 사진을 관리자만 읽을 수 있게 제한합니다.

게시 후 관리자 페이지 → **열람실 → 보안 규칙 점검**을 누르고, 실제 사진 첨부 폼 제출과 좌석 예약을 각각 한 번 확인하세요. **웹사이트 코드와 규칙의 게시 순서를 맞춰야 합니다.** 새 웹사이트를 먼저 공개하고 규칙을 늦게 게시하면 사진을 포함한 제출·예약이 거부됩니다.

사진은 Firebase Storage 대신 브라우저에서 JPEG로 압축한 뒤 Firestore의 관리자 전용 문서에 저장합니다. Spark 무료 요금제를 쓸 수 있지만 Firestore 무료 저장 용량은 유한합니다. 응답을 삭제할 때 사진도 함께 지워지며, 지난 좌석 구간의 사진은 관리자 화면에서 정기적으로 삭제해 주세요. 구글 시트 연동에는 사진을 보내지 않고 텍스트 응답만 보냅니다.
폼 하나에서 올릴 수 있는 사진은 소속 인증 사진을 포함해 최대 2장입니다.
