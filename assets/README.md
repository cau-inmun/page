# assets 폴더

## 로고 넣기 (필수)

학생회 로고 원본 파일을 이 폴더에 **`logo.png`** 라는 이름으로 저장하세요.

- 권장: 배경이 투명한 정사각형 PNG, 512×512px 이상
- 원형 링(‘중앙대학교 인문대학 / 제15대 학생회 연’ 글자 포함) 버전을 쓰면 홈 화면 상단에 가장 잘 어울립니다.

`logo.png` 가 없으면 자동으로 ‘연’ 글자 대체 마크가 표시되므로 페이지가 깨지지는 않지만,
실제 로고를 넣어야 완성된 모습이 됩니다.

## 공지에 이미지 넣기

포스터 등 이미지를 이 폴더에 올린 뒤(`assets/poster-0901.jpg`),
공지 작성 도구(`admin.html`)의 **이미지 주소** 칸에 `assets/poster-0901.jpg` 를 적으면 됩니다.

## 파일 목록

| 파일 | 용도 |
| --- | --- |
| `logo.png` | 로고 (직접 추가해야 합니다) |
| `favicon.svg` | 브라우저 탭 아이콘 |
