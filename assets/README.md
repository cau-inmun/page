# assets 폴더

## 로고

화면에 쓰이는 파일은 **`logo.png`** 하나입니다.
상단바(26px 배지)와 홈 화면 큰 로고가 모두 이 파일을 씁니다.

- 지금 들어 있는 것 : 붓글씨 ‘연’ (900×673, 배경 투명)
- 원본 : `연 로고.png` (4320×4320) 에서 여백을 잘라내고 줄인 것입니다

### 바꾸려면

새 로고를 **배경이 투명한 PNG** 로 만들어 `logo.png` 로 덮어쓰세요.
글씨 둘레의 빈 여백은 잘라내는 편이 좋습니다 — 26px 배지 안에서 글씨가
그만큼 커집니다. 가로세로 비율이 달라지면 두 곳을 함께 고쳐주세요.

- 모든 html 의 `<img src="assets/logo.png" ... width="900" height="673">`
- `css/style.css` 의 `.hero__logo { aspect-ratio: 900 / 673; }`

> 로고 글씨색이 옅어서(#D8C3A5) 상단바처럼 작게 나오는 곳에서는 흐리게 보입니다.
> 배경 없이 로고만 놓는 방식이라 그렇습니다. 또렷하게 하시려면
> `css/style.css` 의 `.topbar__mark` 에 배경색을 주면 됩니다.

`logo.png` 가 없으면 자동으로 ‘연’ 글자 대체 마크가 표시되므로
페이지가 깨지지는 않습니다.

## 공지에 이미지 넣기

포스터 등 이미지를 이 폴더에 올린 뒤(`assets/poster-0901.jpg`),
공지 작성 도구(`admin.html`)의 **이미지 주소** 칸에 `assets/poster-0901.jpg` 를 적으면 됩니다.

## 파일 목록

| 파일 | 용도 |
| --- | --- |
| `logo.png` | 화면에 쓰이는 로고 (900×673, 투명 PNG) |
| `연 로고.png` | 지금 쓰는 로고의 원본 (4320×4320) |
| `인문대 로고 연.png` | 다른 버전 원본 — 보관용, 화면에서는 안 씁니다 |
| `favicon.svg` | 브라우저 탭 아이콘 |
